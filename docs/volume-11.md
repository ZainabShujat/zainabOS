# Chapter 1

# Philosophy

Every visual decision should answer one question.

> **"Would a human actually live here?"**

Not

"Would this look good on Dribbble?"

Not

"Would this get 10k likes on Behance?"

This house is lived in.

Not staged.

# Final Commandment

> **The goal is not photorealism.**
>
> The goal is **emotional realism.**
>
> Someone should believe that if they returned tomorrow, the notebook would still be open, the coffee might be colder, another page might have been written, and the sunlight would fall on the desk a little differently.
>
> When people stop seeing polygons, pixels, CSS, shaders, and UI components...
>
> ...and start believing they're standing in someone's study...
>
> **the art direction is finished.**

## My one addition to the roadmap

Looking back at all eleven volumes, I think the original plan is missing one document that every large game studio has:

> **Volume XI.5: The Rules Bible** (or fold it into the Master Blueprint).

Not philosophy. Not visuals. Just immutable laws.

Things like:

* Nothing teleports.
* Every object has provenance.
* Every sound has a source.
* Every room has exactly one emotional anchor.
* Every new feature must make the world feel older, not newer.
* AI never invents memories.
* No interface may replace a physical object if a physical interaction is possible.
* Every artifact must be connected to at least one other artifact.
* Every room must be understandable in silence.
* If a feature makes the house feel more like software than architecture, it is rejected.

Studios like Nintendo, Pixar, and Valve often have these kinds of "non-negotiable rules." They prevent hundreds of small decisions from slowly eroding the original vision over the years.

I think a project intended to live for decades deserves that kind of constitution.

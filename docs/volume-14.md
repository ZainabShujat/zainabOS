# Chapter 1

# Philosophy

Most software thinks in versions.

Version 1.

Version 2.

Version 3.

The museum rejects versions.

It thinks in years.

The house doesn't reboot.

It ages.

```text

↓

Five Years

↓

Twenty Years

↓

Lifetime
```

it probably doesn't belong.

# Appendix B

# Evolution Rules

Every new room must satisfy:

```yaml
Why does it exist?

What life event created it?

Which existing room became insufficient?

What emotion does it introduce?

How does it connect to the rest of the house?

Will it still matter in twenty years?

What becomes richer because of it?
```

A room is never built because there's empty space.

It is built because there is no longer enough meaning in the existing space.

# Final Commandment

> **Do not design a website that grows larger.**
>
> Design a world that grows older.
>
> Larger worlds impress people for a moment.
>
> Older worlds stay with them.
>
> One day, decades from now, someone should wander into the study, notice the faded notebook from your university years resting beside the latest research journal, hear the same old clock still ticking on the wall, and understand something remarkable:
>
> **Nothing here was preserved because it was important.**
>
> **It became important because it was preserved.**
